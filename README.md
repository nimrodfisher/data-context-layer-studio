# Data Context Layer Studio

Local-first studio for data teams to interview sources, capture domain context, and export governed Cursor/Claude skills as a ready-to-use ZIP.

## Quick start

```sh
corepack enable
corepack pnpm install
corepack pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## What you can do

- Chat with context onboarding and load MCP connectors from your Cursor environment
- Author domain, sources, business language, metrics, caveats, and governance
- Download a complete skill ZIP matching the domain template hierarchy
